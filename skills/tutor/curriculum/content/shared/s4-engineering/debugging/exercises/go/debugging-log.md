# Debugging log

Your lab notebook for the three seeded bugs. Fill it in **as you work**, not
from memory afterwards — the half-formed hypotheses and the ruled-out wrong
turns are the valuable part. Your tutor reviews this log with the same weight
as the code.

Copy the template below once per bug (the tests will tell you which functions
are guilty). Keep entries short: one line each is fine.

```text
## Bug: <function name>

Symptom:       <failing test(s) and the exact got/want message>
Pattern:       <which cases PASS, and what that rules out already>
Minimal repro: <the smallest input that still fails>

Hypotheses:
  1. <suspected cause>  →  experiment: <what you did>
     result: <what happened>  →  ruled out / confirmed
  2. …

Instrument:    <delve session / prints / t.Logf — what you inspected>
Root cause:    <one sentence>
Fix:           <one sentence — why it is the smallest correct change>
```
