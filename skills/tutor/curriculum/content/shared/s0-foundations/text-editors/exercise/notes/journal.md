# Editor tour journal

Use this file for the two navigation tasks from the lesson, and to jot down
what each `inventory.json` mistake was.

## Follow a link without the mouse

The hunt begins at [the first clue](../hunt/START.md). Hold `Cmd` (macOS) /
`Ctrl` (Linux) and click the link — the Markdown language server knows where
that path points and jumps you straight there.

## Add a link with autocomplete

On the line below, link to the multi-cursor drill file. Type
`[the drill](..` — the moment you type the `.` (or press `Ctrl+Space`), a
list of paths appears. That list is completions coming from the Markdown
language server; keep going with `../drill/` and pick `palette.txt` from
the suggestions instead of typing the path yourself.
